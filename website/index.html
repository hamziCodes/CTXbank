Your AI keeps forgetting.
CTXbank remembers.

CTXbank is a small notebook that lives inside your project. It writes down what you're building, what you decided, and what to do next — so you (and your AI coding assistant) never start from zero again.

The problem, in plain words

01

AI amnesia

Long chat with your AI assistant? It forgets decisions you made an hour ago and starts suggesting things you already rejected.

02

The Monday problem

You close the laptop on Friday. On Monday, neither you nor the AI remembers where the work stopped.

03

Token burn

Every new chat re-reads your whole codebase just to fix one bug. That's thousands of tokens — and money — wasted on files that never changed.

How it works, at a glance

Four ideas. That's the whole system.

1

The notebook

ctx init creates a memory-bank/ folder: seven small text files describing your project — what it is, how it's built, what you're doing now, what's next.

2

The save button

Done for the day? Run ctx pause. It snapshots your git state and notes, like a save point in a game. ctx resume brings you back in five seconds.

3

The smart reader

Your AI talks to CTXbank through a local server. If nothing changed, it gets a tiny {"unchanged": true} reply instead of re-reading everything. That's the token savings.

4

Your dashboard

ctx ui opens a visual dashboard on your own machine: edit the notebook, browse checkpoints, run audits. Each project has its own private token.

What is what

The vocabulary, in one line each.

memory-bank/
Seven markdown files. The project's notebook. Human-readable, lives in your repo.
Checkpoint
A save point: git state + your notes + what to do next, frozen in time.
MCP server
The local bridge your AI assistant uses to read the notebook without re-reading your code.
Project token
A private key for one project. It unlocks that project's dashboard. Created by ctx token.
Dashboard
The visual app at localhost:4242. Runs on your machine, nowhere else.

Nothing leaves your machine

CTXbank has no accounts, no cloud, no tracking. The dashboard runs on localhost, your notes stay in your repo, and the whole thing is MIT-licensed open source. If you can read code, you can audit everything it does.

Set me up

Five steps, about two minutes. At the end you'll have a project token — that's your key to the dashboard.

  1. 1

    Install CTXbank

    Pick one. macOS or Linux:

    curl -fsSL https://raw.githubusercontent.com/hamziCodes/CTXbank/main/scripts/install.sh | sh

    Windows (PowerShell):

    irm https://raw.githubusercontent.com/hamziCodes/CTXbank/main/scripts/install.ps1 | iex

    Or, if you have Go:

    go install github.com/hamziCodes/CTXbank/cmd/ctx@latest

    An npm i -g ctxbank / npx package is coming soon.

  2. 2

    Start the notebook in your project

    Open a terminal inside your project folder and run:

    ctx init

    This creates the memory-bank/ folder with blank templates. If your project already has code, run ctx audit --apply and CTXbank will fill in the tech details automatically.

  3. 3

    Get your project token

    This is the important one. Your token is a private key for this project only. You'll paste it on the Connect page to open your dashboard.

    ctx token

    Copy the token it prints and keep it somewhere safe, like a password manager. Lost it or shared it by accident? ctx token --regenerate makes a new one and kills the old.

  4. 4

    Launch your dashboard

    ctx ui

    This starts the dashboard on your own machine (http://localhost:4242) and opens it in your browser. Leave the terminal running while you use it; press Ctrl+C to stop.

  5. 5

    Connect

    Go to the tab, paste your project token, and open your dashboard. From now on, everything you do — checkpoints, notes, audits — shows up there.

Everyday commands

Connect your dashboard

Your dashboard runs on your machine. Paste your project token below and this page will reach out to it — nothing is sent anywhere else.

Enter your token and test the connection. Your dashboard must be running (ctx ui).

Don't have a token? — it takes two minutes: install CTXbank, run ctx init, then ctx token.

Heads up: your browser may ask permission for this page to reach your local network — allow it once and the check will go through.

How the connection works

1

You paste the token

It stays in this page. It's sent only to localhost — your own computer — never to us.

2

We knock on your dashboard

"Test connection" asks your local dashboard for its status. If the token matches, it answers with your project name.

3

You open it

"Open dashboard" launches your local dashboard in a new tab. Everything you do there is reflected instantly — it's the same app.
