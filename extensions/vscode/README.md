# CTXbank VS Code Extension

Official Visual Studio Code and Cursor extension for **CTXbank**, the deterministic memory bank and project lifecycle engine for AI coding assistants.

## Features
- **Active Focus & Budget Guard:** Real-time visibility into `activeContext.md` and token budgets (<150 lines).
- **Architecture & Memory Flow:** Interactive visual tree graph of your project's memory bank files.
- **Instant Checkpointing:** 1-click snapshots directly from the activity bar sidebar.
- **Zero Token Waste:** Works in tandem with CTXbank's delta-caching engine.
